# Customer Churn Prediction using Machine Learning

## Project Overview

This project builds a customer churn prediction system to identify customers who are likely to discontinue a service. It uses classification algorithms and handles class imbalance to improve predictive performance.

## Objectives

- Analyze customer behavior and churn patterns.
- Clean and preprocess customer data.
- Perform exploratory data analysis.
- Handle imbalanced classes using SMOTE.
- Train Random Forest and XGBoost classifiers.
- Evaluate and compare classification performance.

## Technologies Used

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Imbalanced-learn
- XGBoost
- Joblib

## Methodology

1. Dataset Loading and Inspection
2. Data Cleaning and Exploratory Data Analysis
3. Feature Preprocessing and Encoding
4. Train-Test Split
5. Class Imbalance Analysis
6. SMOTE Oversampling
7. Random Forest Classification
8. XGBoost Classification
9. Model Evaluation and Comparison
10. Final Model Selection and Saving

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
- ROC-AUC
